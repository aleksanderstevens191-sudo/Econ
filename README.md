# E251 Modules 5–8 Study Guide

Interactive study guide for ECON E251 (Fall 2026), Modules 5–8, with Midterm 2 review, the Midterm 1 practice set and a practice-exam generator.

Open `index.html` in any browser. It's a single self-contained static page (fonts load from Google Fonts), so it needs no build step.

## Deploy on Vercel

Import this repo at https://vercel.com/new, keep the framework preset as **Other**, leave the build command empty, and deploy. Every push to the default branch redeploys.

- Short notes per section, each followed by a quiz question
- Midterm 2 review: topic checklist, a graph lab for the nine graphs on the review list, and the 25 practice questions with figures
- Mixed checks: after every 2–3 sections, a six-question interleaved quiz pulls from those sections and earlier modules, with the topic hidden until you answer
- Term quiz: all 72 key terms for Modules 5–8 as multiple choice, meaning → term and term → meaning, with wrong options from the same module; instant feedback with the meaning and an example, and misses come back a few questions later
- Study together: a two-person routine (take turns teaching a topic out loud, then both answer mixed questions and compare). Two laptops join with a 4-letter room code: messages are encrypted with the code and sent through several free public Nostr relays at once (no accounts or backend; `vendor/` holds the nostr-tools 2.17.0 browser bundle used for signing), or both share one device
- Exam generator: new randomized 12, 25 or 40-question practice midterms (fresh graphs, tables and numbers each time), graded with worked answers
- Seven animated graph explainers (SVG motion graphics) with step chapters, optional narration and checkpoint questions
- Two interactive graphs: deadweight loss by quantity, and tax incidence by elasticity
- Worked examples followed by practice with hints
- Spaced, interleaved review queue (1, 3, 7, 14, 30 days), saved in the browser's local storage

Notes summarize the Top Hat module pages. Practice answers were worked out for this guide, not taken from Top Hat's key.
